Power BI Project: Insurance Claims Analysis Dashboard
Overview
This Power BI dashboard presents a comprehensive analysis of insurance claims data across different regions of Iran. The dashboard includes visualizations that display the number of insurance claims by province, the growth of insurance claims over the years, and the percentage of claims against the total number of claims per province.

The dashboard is designed to help stakeholders understand trends in the insurance industry, identify patterns in claims across different regions, and make data-driven decisions to improve the performance and coverage of the insurance system.

Features
Map Visualization (Synoptic Panel): The Synoptic Panel is used to display the number of insurance claims in each province of Iran. The map uses color coding to show the variation in claim volume.
Line Chart: Tracks the growth of insurance claims over time (from 1399 to 1401 in the Persian calendar).
Table: Lists the total number of claims and the percentage of claims relative to the total number of claims by province.
Components
Data Source:

The data used in this dashboard is related to insurance claims from different provinces in Iran.
Visualizations:

Synoptic Panel Map: Visualizes the number of claims per region with varying shades using the Synoptic Panel for detailed geographic representation.
Line Chart: Represents the growth of insurance claims over the years.
Table: Displays detailed information regarding the number of claims and the calculated percentage of claims for each province.
Filters:

The dashboard includes a filter that allows users to interactively choose a specific province, dynamically updating all other visualizations based on the selected region.
Calculation Logic:

The dashboard calculates the percentage of claims relative to the total claims for each province.
Usage
Interacting with the Synoptic Panel Map:
Click on any province in the map visualization to filter data and update the other visualizations based on the selected region.
Analyzing Claim Growth:
Use the line chart to track the growth of insurance claims from 1399 to 1401, identifying key trends and fluctuations.
Viewing Detailed Data:
The table provides detailed information on the total claims in each province, along with the calculated percentage of claims relative to the total.
Requirements
Power BI Desktop (latest version)
Insurance Claims Dataset (provided)
How to Import the Data
Open Power BI Desktop.
Go to the "Home" tab and select "Get Data".
Choose the relevant data source (Excel, CSV, or database).
Load the dataset into Power BI.
Use the data to create the visualizations as shown in the dashboard.
